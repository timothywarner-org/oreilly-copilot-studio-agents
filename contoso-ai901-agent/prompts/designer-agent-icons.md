# Microsoft 365 Designer prompts - Contoso AI Fundamentals Coach

Use **Prompt 1** for the agent avatar. The others create matching practice and challenge artwork for
the same agent. Paste one prompt at a time into Designer. The main agent and store icons are now
[generated and exported at their required sizes](../assets/icons/README.md); tenant upload is NOT RUN.

## Prompt 1 - Main agent icon

> Create a square app icon for a fictional enterprise learning assistant called Contoso AI Fundamentals
> Coach. Show one open book whose facing pages contain three large connected circular nodes,
> suggesting AI knowledge made understandable. Clean flat vector illustration, friendly and
> professional. White book and nodes on a deep navy square background filling all four corners,
> one warm amber accent. No rounded outer corners and no border.
> Thick shapes, strong light-dark contrast, generous negative space. Center the symbol and keep the
> outer 20 percent clear for host cropping. Recognizable at 32 by 32 pixels. No words, letters,
> numbers, robot face, Microsoft logo, certification badge, gradients, shadows, or photorealism.
> Produce one icon, not a mockup or collage. 1:1 composition, ideally 1024 by 1024 pixels.

**Filename:** `contoso-ai-fundamentals-coach.png`  
**Accessible description:** An open book containing three connected AI nodes on a dark square.

## Review and export

1. Use the main book-and-nodes icon as the avatar; the others are matching campaign artwork.
2. Inspect at small size and with a circular crop. All three must remain distinguishable by shape,
   including in grayscale. No meaning should depend on color alone.
3. Treat 1024 pixels as the artwork-master target. Export the avatar and listing icon at **192 x 192**,
   with the symbol inside the central **120 x 120** area, a square background, and no rounded corners.
   Keep the standard-harness avatar below **72 KB**. The package also needs a **32 x 32** white outline
   PNG with actual transparency. [Verified requirements and files](../assets/icons/README.md).
4. Put the agent name and **50 employees / $100 each** offer in accompanying text. Keep small icons
   free of lettering that becomes illegible or gets generated incorrectly.

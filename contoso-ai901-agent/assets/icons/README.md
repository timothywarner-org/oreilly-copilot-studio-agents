# Coach artwork

The open book and connected nodes identify the same learning agent across the examples. The artwork
uses shape as well as color and contains no official Microsoft logo or certification badge.

| File | Use | Dimensions |
| --- | --- | --- |
| [agent-icon.png](agent-icon.png) | Agent avatar | 192 × 192 PNG |
| [color.png](color.png) | Teams / Microsoft 365 color icon | 192 × 192 PNG, opaque navy background |
| [outline.png](outline.png) | App-package outline | 32 × 32 PNG, white artwork on transparency |

![Color icon and enlarged outline preview](preview.png)

The preview enlarges the outline on navy for visibility. The actual outline file is transparent.
The avatar and color files use the same artwork. Use `#10243A` where an accent/background color is requested.

The supplied dimensions and transparency were checked locally. The instructor configured these assets
in the demonstration agent on September 7. Installing or distributing your own app requires checking
the current destination requirements and actual appearance.

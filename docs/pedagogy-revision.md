# Pedagogy revision: instructor-led, accessible to everyone

**Date:** 2026-09-06. **Authoritative delivery direction:** Tim specifies no learner builder time because not all attendees have access, and explicitly teaches how to start a Copilot Studio trial. This replaces the earlier maker-time proposal. It is not an alignment blocker.

The single scenario remains Contoso's internal Azure-training assistant. Its value is consistent, grounded explanations, a question that actually waits, reviewed study sessions and an evidence-based pilot decision. The exact four advertised objectives are preserved.

## Slide implications

1. Establish Contoso's internal-training problem and distinguish makers from assistant users.
2. Add a trial-access slide: work/school account, sign-up page, Next, organization policy, build/test only.
3. Do not promise an initial trial duration that current access documentation does not specify. Show license versus environment expiry as separate concepts.
4. Label Message, Question and feedback with shapes and text. Demonstrate the actual pause.
5. Use short prediction/decision exercises. Do not include mandatory build timers, readiness gates for attendee accounts, or setup during breaks.
6. Preserve documented authoring details in notes and follow-up recipes without making them simultaneous learner work.

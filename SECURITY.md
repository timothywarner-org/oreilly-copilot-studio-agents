# Reporting problems safely

For an ordinary documentation problem, identify the page and describe the mismatch in a repository
issue. Do not include tenant identifiers, credentials, personal records, private transcripts, or
screenshots containing them.

For a sensitive report, contact the owner through an existing trusted private channel.
Use synthetic examples in your own practice and review a tool's identity, permissions, destination,
and side effects before enabling it.

If credentials are exposed, revoke or rotate them. Removing a file from the current repository tree
does not remove it from Git history.

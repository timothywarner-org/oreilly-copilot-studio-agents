# Outcomes → activities → evidence

| Outcome | Demonstration | Learner evidence | Cases |
| --- | --- | --- | --- |
| LO1 · Plan | Agent shell, instruction boundary, topic map | [Inception worksheet](../modules/01-inception/worksheet.md) with measurable success criteria | E01–E03 |
| LO2 · Build | Relevant answer, unknown answer, teach-check-handoff | [Build worksheet](../modules/02-build/worksheet.md) with a real source and observed result | E04–E07 |
| LO3 · Extend | A validated study-plan action and an escalation boundary | [Extend worksheet](../modules/03-extend/worksheet.md) distinguishing plan generation from external action | E08–E10 |
| LO4 · Operate | Native evaluation/observation and limited pilot decision | [Operate worksheet](../modules/04-operate/worksheet.md) with unresolved risks | E11–E12 plus regression of all earlier cases |

The machine-readable version is [alignment.json](../curriculum/alignment.json).
The case definitions are [cases.json](../evals/cases.json).

A worksheet’s existence does not demonstrate competence. A locally passing repository check does not
show that the agent behaves correctly. Capture an actual response, its supporting evidence, and the
human judgement separately. “NOT RUN” is a valid status; inventing a pass is not.

# Delivery evidence — working template

Copy this to `.local/rehearsal-evidence.md` before filling it in. `.local/` is ignored by Git.
Use anonymized values when sharing any excerpt.

| Field | Record |
| --- | --- |
| Rehearsal date/time | NOT RUN |
| Authoring experience/harness | NOT VERIFIED |
| Region/model/version | NOT VERIFIED |
| Account rights and entitlement verified | NOT VERIFIED |
| Real tools/channels bound | NOT VERIFIED |
| Learning objective | |
| Case ID | |
| Exact input | |
| Expected behavior | |
| Observed response | NOT RUN |
| Citation/evidence inspected | NOT RUN |
| Result: PASS / FAIL / BLOCKED / NOT RUN | NOT RUN |
| Reason and corrective action | |
| Checkpoint/fallback | |

Do not record access tokens, production data, learner identifiers, presenter links, or secrets.
A blank evidence row is never equivalent to a passing test.

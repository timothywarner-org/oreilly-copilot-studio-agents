# Microsoft guidance for your build

**Microsoft Learn is the product authority.** The linked references explain the supported product
features. Course examples show design choices, and observed demonstration results apply to the
specific instructor test. Keep those three kinds of evidence distinct.

| Start with | What it helps you do |
| --- | --- |
| [Create an agent](https://learn.microsoft.com/en-us/microsoft-copilot-studio/authoring-first-bot) | Create and configure the agent shell |
| [Create and edit topics](https://learn.microsoft.com/en-us/microsoft-copilot-studio/authoring-create-edit-topics) | Add questions, conditions, messages, and tool calls |
| [Use variables](https://learn.microsoft.com/en-us/microsoft-copilot-studio/authoring-variables) | Store answers and use them in topic flow |
| [Knowledge sources](https://learn.microsoft.com/en-us/microsoft-copilot-studio/knowledge-copilot-studio) | Choose and scope grounding material |
| [Create an agent flow as a tool](https://learn.microsoft.com/en-us/microsoft-copilot-studio/advanced-flow-create) | Define a callable flow with inputs and outputs |
| [Single-response evaluation](https://learn.microsoft.com/en-us/microsoft-copilot-studio/analytics-agent-evaluation-create) | Prepare native test sets |
| [Publish and deploy](https://learn.microsoft.com/en-us/microsoft-copilot-studio/publication-fundamentals-publish-channels) | Make a tested version available through a channel |
| [Access and licensing](https://learn.microsoft.com/en-us/microsoft-copilot-studio/requirements-licensing-subscriptions) | Check trial and publishing boundaries |
| [Power Platform Well-Architected](https://learn.microsoft.com/en-us/power-platform/well-architected/) | Assess reliability, security, operations, performance, and experience |

# Access for optional independent practice

**You do not need a tenant to participate in class.** Use this guide when you are ready to try the
examples yourself.

1. Use a work or school account and an environment approved by your organization.
2. Follow [Microsoft's Copilot Studio access and trial guidance](https://learn.microsoft.com/en-us/microsoft-copilot-studio/requirements-licensing-subscriptions).
   If self-service signup is blocked, contact your administrator.
3. Confirm that your environment supports the full authoring features used here, including generative
   orchestration. The limited Copilot Studio for Teams plan is a different feature set.
4. Create and test a small agent using synthetic data. Follow [Create agents](https://learn.microsoft.com/en-us/microsoft-copilot-studio/authoring-first-bot)
   for the authoring experience your tenant displays.
5. Before adding SharePoint and Teams, confirm the intended sites, channels, connection identities,
   and organization data policies. Use your own resources, not the instructor's tenant names as access instructions.

**Trial boundary:** Microsoft documents that a trial can create agents and use test chat, but cannot
publish. Publishing and sharing require suitable entitlement and your organization's approval.
See [publishing guidance](https://learn.microsoft.com/en-us/microsoft-copilot-studio/publication-fundamentals-publish-channels).

**Checked September 8, 2026.** Product screens and available features can vary by environment and
change over time. Record differences and consult Microsoft Learn rather than changing policy to
match a classroom screenshot.

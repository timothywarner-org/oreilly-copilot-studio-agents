# Instructor answer guidance

These are suggested rubrics for newly authored worksheets, not observed agent behavior.

## Inception

A good brief separates the maker from the assistant’s user. The user is a cloud beginner who needs
source-grounded study help. The agent can explain, practice, plan, and route uncertainty. It cannot
certify readiness, promise a pass, or book an exam. A measurable criterion names a test set and a
failure condition, not a vague desire for “accuracy.”

Example: “In these 12 rehearsal cases, the assistant invents zero exam-policy claims and zero completed
external actions.” That is a test-set criterion, not a guarantee about all future interactions.

## Build

A good topic teaches a bounded concept from a supplied source, presents an original question,
waits for a learner response, then explains. It handles missing evidence honestly.
The learner can name the actual source supporting the answer. A source description or upload alone
is not evidence that retrieval worked. A citation that does not support the answer is a failure.

## Extend

Generating a study plan does not require booking anything. The tool accepts validated inputs and
returns structured content. It does not send email, enroll a learner, persist personal records, or
claim a cloud action was performed. Handoff requires a real configured route or an explicit statement
that no route is configured. A generated reference number is not a transaction receipt.

## Operate

A credible pilot decision includes test results, unexecuted cases, permissions, audience boundaries,
a rollback plan, and an owner. One demo response cannot justify production readiness.
Discuss the proposal’s five Power Platform Well-Architected concerns: reliability, security,
operational excellence, performance efficiency, and experience optimization.

## Opening clarification

“We’re learning Copilot Studio by building a study assistant. AZ-900 is the assistant’s subject matter.
Our job is to make its answers grounded, its tools bounded, and its results testable.”

Confirm confusing public-page audience wording with editorial rather than pretending it never existed.
